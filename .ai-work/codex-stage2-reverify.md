## 확인 요청
1. 검사: `npm install` → `npm run typecheck` → `npm test` → `npm run lint` → `npm run build`. 각 종료 코드를 기록한다.
2. 375×812 브라우저(`npm run dev` 후 `#/gear`)에서 다음을 확인한다.
   - 장비 등록 화면에 가로 넘침이 없다.
   - 등록 → 목록 → 수정 → 새로고침 후 유지 → 삭제 취소 → 실제 삭제가 된다.
   - 검증 규칙이 지켜진다: 공백뿐인 이름 거부, 숫자 항목의 유한값·최소 < 최대·간격 > 0, 선택지 빈 목록 거부.
   - 수정 후에도 장비 ID·조절 항목 ID·`createdAt`이 그대로다.
   - 저장소 쓰기 실패(`Storage.prototype.setItem` 모의)를 재현한다. **저장 버튼을 누른 직후 안내가 스크롤 없이 화면 안에 보이는지**, 입력이 유지되는지, 성공 알림이 없는지, 저장된 데이터가 그대로인지 확인한다.
   - 저장하지 않은 편집이 있을 때, 탭 이동과 브라우저 뒤로가기에서 확인 대화상자가 뜨고 기록 위치가 유지된다.
   - 콘솔 오류가 없다.
3. `beforeunload` 브라우저 기본 경고창은 개발자 환경에서 판정하지 못했다. 확인할 수 있으면 확인하고, 못 하면 미확인으로 기록한다.
4. 장비를 수정·삭제해도 기존 톤 스냅샷이 그대로인지(`src/store/gear.test.ts`) 확인한다.

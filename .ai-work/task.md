# 작업 명세 — 0단계: 확인 및 계획

## 요청
톤노트(모바일 우선 웹앱) 첫 버전의 화면·데이터 모델·폴더 구조·구현 단계를 계획한다. 앱 구현은 하지 않는다.

## 완료 기준
- 현재 폴더와 적용 지침(AGENTS.md 등) 확인 결과 기록
- 필요한 화면, 데이터 모델, 폴더 구조 제안
- 구현 4~5단계와 단계별 완료 조건
- 위 내용을 `PROJECT_PLAN.md`에 작성
